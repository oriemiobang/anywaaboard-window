Keyboard Shortcuts

Use Right Alt (AltGr) as your modifier. Hold Shift for uppercase.

Shortcut Types Description
Right Alt + A ä / Ä a with diaeresis
Right Alt + E ë / Ë e with diaeresis
Right Alt + I ï / Ï i with diaeresis
Right Alt + O ö / Ö o with diaeresis
Right Alt + X ø / Ø o with stroke
Right Alt + D dh / DH digraph dh
Right Alt + N nh / NH digraph nh
Right Alt + G ng / NG digraph ng
Right Alt + T th / TH digraph th
Right Alt + Y ny / NY digraph ny
