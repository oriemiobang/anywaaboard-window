# Anywaa Board privacy policy

Anywaa Board processes keyboard input locally in the browser. The extension
does not transmit typed text, dictionary entries, or browsing history to
Bella Technologies or any other server.

The personal dictionary and per-site enable/disable preference are stored
locally using the browser's extension storage API. These values are used only
to provide keyboard
shortcuts, suggestions, and the settings shown in the popup.

The extension requests access to web pages so it can intercept the documented
Right Alt combinations in editable fields. It does not read or store page
content outside the text needed to perform an insertion or local suggestion.

For privacy questions, contact Bella Technologies through the project's
official support channel.

This policy must be published at a stable HTTPS URL before store submission.
