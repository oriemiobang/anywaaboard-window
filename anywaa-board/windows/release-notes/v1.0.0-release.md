# Anywaa Board for Windows v1.0.0 — Dha Anywaa Keyboard

Official release of **Anywaa Board for Windows** — the easiest way to type in **Dha Anywaa (Anuak)** on Windows 10 and Windows 11.

---

### ⬇️ Direct Download
- 💾 **[AnywaaBoard.exe](https://github.com/oriemiobang/anywaaboard-window/releases/download/v1.0.0/AnywaaBoard.exe)** (1.38 MB — Standalone, Self-Installing)

---

### 🚀 Key Features
- **Zero-Setup Installation:** Simply download and run `AnywaaBoard.exe`. It configures itself and starts automatically whenever Windows boots.
- **Fast Startup:** Auto-starts right when you log into Windows, without delays.
- **System-Wide Typing:** Works everywhere in Windows — Microsoft Word, Excel, Chrome, Edge, Firefox, Telegram, WhatsApp Desktop, Discord, Notepad, etc.
- **Standard Keyboard Unchanged:** Your regular US keyboard works exactly the same. Hold **Right Alt (AltGr)** only when typing Anywaa characters.

### ⌨️ Key Mappings

#### Special Vowels
| Key Combination | Output | Description |
|---|---|---|
| `Right Alt + A` | **ä** | Lowercase a with diaeresis |
| `Right Alt + Shift + A` | **Ä** | Uppercase A with diaeresis |
| `Right Alt + E` | **ë** | Lowercase e with diaeresis |
| `Right Alt + Shift + E` | **Ë** | Uppercase E with diaeresis |
| `Right Alt + I` | **ï** | Lowercase i with diaeresis |
| `Right Alt + Shift + I` | **Ï** | Uppercase I with diaeresis |
| `Right Alt + O` | **ö** | Lowercase o with diaeresis |
| `Right Alt + Shift + O` | **Ö** | Uppercase O with diaeresis |
| `Right Alt + X` | **ø** | Lowercase o with stroke |
| `Right Alt + Shift + X` | **Ø** | Uppercase O with stroke |

#### Digraphs
| Key Combination | Output | Description |
|---|---|---|
| `Right Alt + D` | **dh** / **DH** | Digraph dh |
| `Right Alt + N` | **nh** / **NH** | Digraph nh |
| `Right Alt + G` | **ng** / **NG** | Digraph ng |
| `Right Alt + T` | **th** / **TH** | Digraph th |
| `Right Alt + Y` | **ny** / **NY** | Digraph ny |
